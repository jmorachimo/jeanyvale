INVITACIÓN DE BODA DIGITAL — RÚSTICO CHIC ELEGANTE

ARCHIVOS
- index.html: contenido principal
- styles.css: diseño y colores
- script.js: cuenta regresiva y RSVP por WhatsApp
- assets/favicon.svg: icono del sitio

PARA PROBARLA
1. Descomprime la carpeta.
2. Abre index.html en Chrome, Edge o Safari.

PARA PERSONALIZARLA
En index.html cambia:
- Nombres de los novios
- Fecha
- Ceremonia y recepción
- Horarios
- Dress code
- Texto de historia
- Fecha límite de RSVP

En script.js cambia:
- WEDDING_DATE
- WHATSAPP_NUMBER

PARA PUBLICARLA GRATIS
Puedes arrastrar la carpeta completa a Netlify Drop o subirla a Vercel/GitHub Pages.

FOTOS
Reemplaza las tarjetas de galería por imágenes guardadas en la carpeta assets.
Ejemplo HTML:
<img src="assets/foto1.jpg" alt="Valeria y Sebastián" />

NOTA
Esta versión usa datos ficticios de demostración. Cuando tengas los datos reales, se reemplazan sin necesidad de rehacer el diseño.
